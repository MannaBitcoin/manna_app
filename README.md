## **Manna** is a self-custodial Bitcoin wallet for Lightning, and Bitcoin payments.

This version is still in beta...

Simple enough for everyday use.
- Your keys, your coins
- Lightning + on-chain using spark
- Built-in Point of Sale
- BTC Map, Bitcoin price chart, End-to-end encrypted chat
